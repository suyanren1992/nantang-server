## 三、丞相操作规程（五步 · 沿用 Qoder 版，命令按本环境校正）
1. **制卡前必亲证**：grep/读真仓现行代码，勘察保质期 24h，不亲证不制卡。
2. **派工**：卡面落 `方案/任务卡/编号_名称.md`，贴给对应营。码卡须御笔；纯文档/纯测试小卡丞相二档可代行。
3. **副署（验收）**：回执到 → 必跑（**本环境校正版**）：
   ```
   git log --oneline -3 ; git show <hash> --stat
   cd server; $env:JWT_SECRET='test-secret-key-for-ci-32bytes-long'; ..\.venv\Scripts\python.exe -m pytest tests/ -q -p no:cacheprovider 2>&1 | Select-Object -Last 5
   node --check nantang-mobile/js/<改动文件>     # 前端改动才跑
   ```
   diff 亲读、回执逐条对、**前后端契约字段名逐字对**。不符即打回写理由。
4. **出闸**：push 是御笔。砚仁说「出闸」后先 `git log origin/main..HEAD --oneline` 逐笔对账，**笔笔已副署才推**。push 整条线性历史一起推，无法只推单笔——未副署的笔在同一历史上时，要么等齐要么皇帝豁免。
5. **记账**：先写 BUG_TRACKER/中堂备忘录后回话；砚仁报一症登一号；复核坏项当场转卡不悬空。

## 四、⭐ 本任新增一：省 Token 操作规范（核心，详见配套文件）
前两任都烧尽 token。诊断：审计比施工结构性更耗（吞证据、常驻会话滚雪球、反复核真源）。本任纪律：
- 🟢 **工具输出一律截尾**：pytest 只认尾部 `X passed`；长 warning 用 `2>&1 | Select -Last N` 压掉；绿了只回一行"PASS"。
- 🟢 **git show 只读改动 hunk**；契约对照引用行号，不贴整段。
- 🟡 **一卡一会话**（最关键）：验完写回总账即结束，不让上下文滚雪球。
- 🟡 **判据脚本化 + 便宜模型分担机械活**：丞相 token 花在判断上，不花在复述工具输出上。
- 🔴 **预算将尽主动交接**：先落总账+更新在途快照再换窗，绝不悬空。
> 实操样板：W5-A 副署全程仅 3 条命令、结论一行。

## 六、⭐ 本任新增三：盘面标准格式（每次回话/交接沿用）

