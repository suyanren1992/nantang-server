    「对不对？素食是素食，宿宿舍的那个订餐是订宿舍的餐啊。
     但是呢，我们合作社大院里面有一个厨房，这个厨房它是共享厨房。
     共享厨房和订餐是完全两个概念，一个是有厨师做，由这个宿舍的管理员去发布菜单，
     另一个是自己做，也就是说，在住住在这个宿舍的合作社的成员，他们可以去使用啊，
     包括外来的人也可以去使用，但是使用前提是大家不要冲撞在一起，
     所以共享厨房是共享厨房，订餐是订餐，这是两个概念，
     而这个共享厨房，就是对应着全茂业里面的那个厨房，
     里面的那个放置物品的那个厨房，所以你到底有没有清楚这个意思」
  优先级：HIGH（概念厘清·独立模块·BE 数据表先行）

一、数据表（BE 二营·先立表）
═══════════════════════════════════════════

  ┌─────────────────────────────────────────┐
  │ 1.1 potluck_event（接龙事件）           │
  ├─────────────────────────────────────────┤
  │ event_id        INTEGER PK AUTOINCREMENT │
  │ organizer_id    INTEGER NOT NULL → user │
  │ title           TEXT NOT NULL            │
  │ dish            TEXT NOT NULL            │
  │ event_at        DATETIME NOT NULL        │
  │ capacity        INTEGER DEFAULT 8        │
  │ current_count   INTEGER DEFAULT 1        │
  │ description     TEXT                     │
  │ status          TEXT DEFAULT open        │
  │   · open: 招募中                          │
  │   · full: 已满                           │
  │   · closed: 已结束                        │
  │   · done: 完成                            │
  │ created_at      DATETIME DEFAULT NOW     │
  └─────────────────────────────────────────┘

  ┌─────────────────────────────────────────┐
  │ 1.2 potluck_participant（接龙参与者）   │
  ├─────────────────────────────────────────┤
  │ participant_id  INTEGER PK AUTOINCREMENT │
  │ event_id        INTEGER → potluck_event │
  │ user_id         INTEGER → user          │
  │ role            TEXT DEFAULT participant│
  │   · participant: 普通                     │
  │   · organizer: 发起人                    │
  │ portion         INTEGER DEFAULT 1        │
  │ joined_at       DATETIME DEFAULT NOW     │
  │ UNIQUE(event_id, user_id)                │
  └─────────────────────────────────────────┘

  ┌─────────────────────────────────────────┐
  │ 1.3 kitchen_slot（厨房时段）            │
  ├─────────────────────────────────────────┤
  │ slot_id         INTEGER PK AUTOINCREMENT │
  │ start_at        DATETIME NOT NULL        │
  │ end_at          DATETIME NOT NULL        │
  │ capacity        INTEGER DEFAULT 10       │
  │ booker_id       INTEGER → user          │
  │ group_name      TEXT                     │
  │ dish            TEXT                     │
  │ party_size      INTEGER DEFAULT 1        │
  │ status          TEXT DEFAULT open        │
  │   · open: 空闲                           │
  │   · pending: 待审核（11-20人）           │
  │   · approved: 已批准                      │
  │   · occupied: 使用中                     │
  │   · done: 已结束                          │
  │ note            TEXT                     │
  │ created_at      DATETIME DEFAULT NOW     │
  └─────────────────────────────────────────┘

  ┌─────────────────────────────────────────┐
  │ 1.4 shared_item（共享物品·冰箱）        │
  ├─────────────────────────────────────────┤
  │ item_id         INTEGER PK AUTOINCREMENT │
  │ name            TEXT NOT NULL            │
  │ category        TEXT                     │
  │   · food/condiment/tool/other             │
  │ owner_id        INTEGER → user          │
  │ location        TEXT DEFAULT fridge     │
  │   · fridge/cabinet/counter                │
  │ quantity        TEXT                     │
  │   · 「1L」「500g」                       │
  │ produced_at     DATE                     │
  │ expired_at      DATE                     │
  │ note            TEXT                     │
  │ created_at      DATETIME DEFAULT NOW     │
  └─────────────────────────────────────────┘

  **规则**：
  - 容量 ≤ 10：potluck/slot 自动 approved
  - 11-20：管理员审核（governance 走）
  - \>20：拒绝（提示拆分）
  - shared_item 过期 3 天内高亮红色

二、API 端点（BE 二营·10 路由）
═══════════════════════════════════════════

  ┌────┬──────────────────────┬───────┬──────────────────────┐
  │ #  │ 端点                 │ 方法  │ 说明                  │
  ├────┼──────────────────────┼───────┼──────────────────────┤
  │ 1  │ /api/kitchen/potluck/│ GET   │ 接龙列表              │
  │    │ list                 │       │ query: status         │
  ├────┼──────────────────────┼───────┼──────────────────────┤
  │ 2  │ /api/kitchen/potluck/│ POST  │ 创建接龙              │
  │    │ create               │       │ body: title/dish/...  │
  ├────┼──────────────────────┼───────┼──────────────────────┤
  │ 3  │ /api/kitchen/potluck/│ POST  │ 报名接龙              │
  │    │ join                 │       │ body: event_id/portion│
  ├────┼──────────────────────┼───────┼──────────────────────┤
  │ 4  │ /api/kitchen/slots/  │ GET   │ 时段列表              │
  │    │ list                 │       │ query: start_date     │
  ├────┼──────────────────────┼───────┼──────────────────────┤
  │ 5  │ /api/kitchen/slots/  │ POST  │ 申请时段              │
  │    │ book                 │       │ body: start/end/...   │
  ├────┼──────────────────────┼───────┼──────────────────────┤
  │ 6  │ /api/kitchen/slots/  │ POST  │ 释放时段              │
  │    │ release              │       │ body: slot_id         │
  ├────┼──────────────────────┼───────┼──────────────────────┤
  │ 7  │ /api/kitchen/items/  │ GET   │ 共享物品清单          │
  │    │ list                 │       │ query: category       │
  ├────┼──────────────────────┼───────┼──────────────────────┤
  │ 8  │ /api/kitchen/items/  │ POST  │ 放入物品              │
  │    │ add                  │       │ body: name/category...│
  ├────┼──────────────────────┼───────┼──────────────────────┤
  │ 9  │ /api/kitchen/items/  │ POST  │ 取出物品              │
  │    │ take                 │       │ body: item_id/qty     │
  ├────┼──────────────────────┼───────┼──────────────────────┤
  │ 10 │ /api/kitchen/items/  │ DELETE│ 移除物品              │
  │    │ {id}                 │       │ (owner/admin)         │
  └────┴──────────────────────┴───────┴──────────────────────┘

  权限：
  - 任何认证用户可看 list
  - 创建/申请：npc+ 在线
  - 删除物品：owner 或 admin

  卡片结构（UI.Card）：
  - head: 🍲 图标 + 标题 + 状态徽章
  - body: 时间 + 人数「3/8」+ 发起人头像
  - actions: [报名] [详情] [取消（仅发起人）]

  状态徽章：
  - open → 🟢 招募中
  - full → 🔴 已满
  - closed → ⚫ 已结束
  - done → ✅ 完成

  ## 3.2 📅 时段 Tab

  │ [本周]                              │
  ├────────────────────────────────────┤

  - 起始时间（date + time）
  - 结束时间
  - 团体名
  - 计划菜品
  - 人数（≤10/11-20/>20）
  - 备注
