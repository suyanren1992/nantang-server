# 密钥与环境变量清单

> **铁律**：本文件只列**名称、用途、存放位置、轮换周期**。
> **严禁写入任何真实值、完整密钥、备份文件路径或截图**。
> 真实值存于：Render 环境变量面板 / 砚仁本地 .env（不入 git）/ 密码管理器。

## 应用层

| 变量名 | 用途 | 存放位置 | 轮换周期 | 必需 |
|---|---|---|---|---|
| `JWT_SECRET` | JWT 签发/校验密钥，泄露=任意用户身份伪造 | Render 环境变量 + 本地 .env | 怀疑泄露立即轮换，常规每年 1 次 | 必需 |
| `DATABASE_URL` | Neon Postgres 连接串（含密码） | Render 环境变量 + 本地 .env | Neon 控制台轮换时同步 | 必需 |
| `INVITE_CODES` | 注册邀请码池（逗号分隔） | Render 环境变量 | 按需更换 | 可选（空=关闭邀请制） |
| `FRONTEND_ORIGIN` | 额外 CORS 白名单 | Render 环境变量 | 域名变更时 | 可选 |

## 链上/钱包

| 变量名 | 用途 | 存放位置 | 轮换周期 | 必需 |
|---|---|---|---|---|
| `OP_RPC_URL` | Optimism RPC 节点（含 API key 时视为密钥） | Render 环境变量 | 服务商轮换时同步 | 可选（链扫描器） |
| `NT_TOKEN_CONTRACT` | NT 代币合约地址 | Render 环境变量 | 合约不变即不变 | 可选 |
| `PLATFORM_WALLET_ADDRESS` | 平台冷钱包地址（公开地址，非密钥） | Render 环境变量 | 换钱包时 | 可选 |

## 第三方服务

| 名称 | 用途 | 存放位置 | 轮换周期 |
|---|---|---|---|
| Render API Key | deploy hook / 自动化部署 | 砚仁密码管理器 | 每次人员变动 / 怀疑泄露 |
| Neon DB 密码 | 数据库 root | Neon 控制台 | 季度 |
| Cloudflare Tunnel token（若用） | 内网穿透 | Cloudflare 控制台 | 按需 |
