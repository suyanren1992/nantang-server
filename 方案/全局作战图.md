## 四、批次节奏规则（本轮改制核心）

1. **批次制**：一批一干，一批一批。不滚动发卡、不碎片请旨
2. **皇帝审批点**：每批开工前你批一次（批什么、什么顺序）；批中不打扰，
   只有 🔴 资金/安全/方向变更才中途请旨
3. **收官仪式**：每批末全量 push + 双机检（deploy_check + arch_check）+ 你冒烟 + 本图更新
4. **中途插入**：线上紧急 bug 走快通道直报你；新想法先记入本图「谏言箱」，下一批复议
5. **丞相日报简化**：不再逐卡奏报，每批一封「开批奏 / 收官奏」两封而已
