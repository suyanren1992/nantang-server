# D-23 运维安全常态化（二营）

> 来源：对照体检病根「安全是集中扫一次，非持续做」+「部署后运维安全空白」。
> 施工：豆包 Codex｜验收：Claude Code

## 施工内容（三件套，轻量优先）

1. **依赖漏洞月扫**：`server/scripts/security_scan.py`——pip-audit（或 safety）跑 requirements，
   结果写报告；高危 → 立刻发卡，中低 → 记入月度复核
2. **密钥与环境变量清单**：`方案/运维/密钥清单.md`——只列**名称、用途、存放位置、轮换周期**，
   严禁写入任何真实值；含 JWT_SECRET / DATABASE_URL / INVITE_CODES / Render API 等
3. **月度复核卡模板**：`方案/任务卡/模板_月度安全复核.md`——依赖扫描结果、权限端点抽查
   （抽 3 个端点重放 D-4/D-10 类攻击）、密钥轮换到期检查、墓碑复发检查四节

## 判据（验收方实跑）

1. 扫描脚本实跑出报告（含 0 漏洞也要输出"扫描时间+0 结果"，防静默失效）
2. 密钥清单逐项核对：真实值零出现（grep 已知密钥特征验证）
3. 模板卡可直接复制使用
