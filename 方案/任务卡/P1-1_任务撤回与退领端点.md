> 议定（砚仁 2026-07-27 16:51 规则 + 17:15 丞相三补丁核准）：
> ① 撤回必解冻托管金（钱随单走）② 已领未提交与已提交分野 ③ 取消认领记日志

## 施工内容（三端点 + 一铁律）

1. **发布者撤回**：`POST /api/tasks/{id}/retract`
   - 无人领取 → 任务回 `draft`（草稿箱）+ **task_escrow 解冻全额退回发布者 nt_balance** + ledger 解冻流水
   - 已领未提交 → 409 拒自助，转申请制（见 2）
   - 已提交（有待审核提交）→ 409 不可撤回，只能走校核/拒绝
2. **撤回申请制**：已领未提交时发布者可 `POST /api/tasks/{id}/retract-request` →
   状态「撤回申请中」，管理员可见 → admin `POST /api/tasks/{id}/retract-review`
   （批准=解冻退款+任务回 draft+领取者收到通知 / 拒绝=任务继续）。批准/拒绝二选一，无模糊态。
3. **领取者退领**：`POST /api/tasks/{id}/unclaim` → 移除 claimant、任务回大厅、
   记取消日志（管理员可见，v1 不限次数——先记录后立规）。
4. **钱随单走铁律**：每条解冻/退款都必须有 nt_ledger 流水，nt_balance 与 escrow 同步增减，
   对账等式不破（参考 P0-2 幂等的写法）。

## 命名纪律
- 端点用 `retract`/`unclaim`，**禁止用 withdraw**（避免与提现 withdraw 资金端点混淆）。
