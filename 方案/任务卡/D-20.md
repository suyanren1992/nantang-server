# D-20 测试闭环 · 契约链路冒烟（二营）

> 来源：对照体检病根「功能闭环断裂」（A-7 校核 NT 不到账为典型案例）。
> 施工：豆包 Codex｜验收：Claude Code（必须实跑）

## 施工内容

写 `server/tests/test_e2e_smoke.py`：httpx ASGI 直连，一条脚本走完核心资金闭环——

```
注册 → 登录 → 做任务交校核 → 另一账号 approve → 断言 NT 到账（A-7 回归：id 一致不 404）
→ 发起提现 → 断言 ledger pending + frozen 增加 + 余额扣减
→ admin confirm → 断言 ledger confirmed
→ reject 路径：驳回 → 断言状态 rejected + retry_count+1
→ presence：alice 翻牌 → bob 拉 sync_all → 断言 bob 看到 alice 状态且 alice 数据未被覆盖
```

## 判据（验收方实跑）

1. 脚本全绿贴输出；每一环断言的是**服务端状态**（直查库或接口），不是返回文案
2. 故意把 approve 的 id 改错一位 → 对应断言变红（A-7 不复发）
3. 脚本纳入 D-19 的 pytest 体系，一条命令可跑全部
