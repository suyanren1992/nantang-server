## 二、自测结果

- 静态审查：
  - `API.checkin()` 参数顺序：（roomId, track, checkIn, checkOut, bedNum）→ 服务端 `{room_id, track, check_in, check_out, bed_num}` ✅
  - 单人间 `bedNum=1`，四人间 `_inn._bedNum` 由 select 驱动 ✅
  - 日历已占用日期标记 `occ[ds]` 来自 API `occupied_dates` ✅
  - 状态栏读取 `stay = r.tenant`（API `accommodationStatus` 返回 `{tenant:{...}}`) ✅
  - 退房结算读取 `r.settlement` 字段（total/paid/debt/days/rate）✅
- API 对接路径：
  - `list_inn_rooms` → `rooms[].{id,label,room_type,beds,rate,occupied_dates}` → 房型网格 ✅
  - `checkin` → `{room_id,track:'inn',check_in,check_out,bed_num}` → 预订 ✅
  - `checkout` → 退房结算 → `{ok,settlement}` → 弹明细 ✅
  - `accommodationStatus` → `{tenant:{room_id,bed_num,checkin_date,rate,...}}` → 状态栏 ✅
- 回归风险：**低**。仅改 `ui-phase4.js`（素社民宿独立模块）和 `api.js`（checkin 增加可选参数向后兼容）。合作社 `_showStaySheet()` 一字不改。
