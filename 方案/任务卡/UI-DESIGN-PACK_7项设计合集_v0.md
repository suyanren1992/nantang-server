## ① 新人引导（游戏化）
━━━━━━━━━━━━━━━━━━━━━━━━━━

  - 砚仁原话：「有点像类似于游戏设游戏的一个引导界面一样的。比如说有一个小人，然后一个对话框引导你啊，点这里点那里点那里点这里点这里，然后对整个界面进行一个介绍。这个引导是这样的引导，嗯，引导完之后，他就可以获得少量的NT」
  - **形态**：
    1. 全屏覆盖蒙层（遮罩 + 不可点透）
    2. 小人吉祥物（🐱 或 🐶 emoji，2D 站姿）
    3. 对话气泡：步骤标题 + 文字 + 「下一步」按钮
    4. 高亮目标元素：环形虚线 + 浮动气泡
    5. 进度条：第 3/7 步
  - **步骤序列**（7 步）：
    1. 「欢迎来到南塘」+ 🐱 自我介绍
    2. 「这是你的工作台」+ 高亮工作台
    3. 「这是社区活动页」+ 高亮活动
    4. 「这是田间与厨房」+ 高亮田/厨
    5. 「签到获得 NT」+ 演示签到动作
    6. 「领取你的第一个任务」+ 高亮任务栏
    7. 「完成引导，奖励 30 NT」+ 🎉 弹 NT 到账
  - **触发**：首次 checkin 入住完成时弹（不是工作台任务栏派发）
  - **奖励**：30 NT（从 contribution_pool 走，走现有 addVerification 校核？或系统白送？）
  - **与 NEW-USER-TASK 区别**：
    - 新人引导 = 教学（一次性，7 步，奖励 30 NT）
    - NEW-USER-TASK = 任务派发（持续，N 个任务，每个 5-10 NT）
  - **数据**：user.onboarded (bool) + user.onboarded_at (datetime)
  - **复用块面**：UI.Modal + UI.Card + UI.Icon + UI.Progress
  - **块面缺口**：高亮环形（虚线 + 浮动气泡）= 新组件 UI.Highlight

## ② 工作台快速抽屉（身份触发）
━━━━━━━━━━━━━━━━━━━━━━━━━━

  - 砚仁原话：「成为在地伙伴之后，或者说再进NPC之后，他应该可以快捷输入厨房的一些物品。…成为共建共建人之后…如果他也参加了，但同样也一队那边也要在工作台那边有一个快捷的按钮。它这个快捷按钮是一个抽屉式的」
  - **形态**：
    1. 浮动按钮（FAB）位于工作台右下角
    2. 点击展开抽屉（从右滑入，宽 80%）
    3. 抽屉内按身份动态列出快捷动作
  - **身份 × 动作映射**：
    | 身份 | 抽屉动作 |
    |------|---------|
    | visitor | 入住引导 / 探索 |
    | npc | 放入物品（冰箱）/ 查看库存 |
    | 在地伙伴 | 放入物品（冰箱）/ 厨房报修 / 共享厨房接龙 |
    | 共建人 | 营队活动 / 营队任务 / 营队提案 |
    | admin | 世界终端 / 后台管理 / 紧急广播 |
  - **复用块面**：UI.Modal（抽屉变种）+ UI.Card + UI.ActionSheet
  - **块面缺口**：UI.Drawer（从右滑入抽屉）= 新组件
  - **数据**：user.role（已有）+ role_actions（配置表）

## ④ 大扫除 UI（重设计）
━━━━━━━━━━━━━━━━━━━━━━━━━━

  - 砚仁原话：「大扫除的录入我也不太满意…首先是管理员选中几个位置，然后每周一开始发放选中。你根据人数去选中位这个区域内容几个人或者说跟根据人数去做啊这个区域的一些这次大扫除的一个区域的划分，比如说有三个人，那就点4个或者是5个6个…总的来说，就是要根据实际情况，先是这个管理员先确定好，然后呢，开始跟选英雄一样的，每个人选中了这个卡牌，然后这卡牌就出现在他的面前，然后就确定了，打扫完之后，就开始发布到小荷叶，就是校和市去，就是这个流程是要有明确的一个选中，然后发送的一个过程」
  - **形态**（5 段式流程）：
    1. **管理员选位置**：地图点选 N 个清扫区域（block 划分）
    2. **系统分配**：根据人数自动算 N×人数/2 个任务
    3. **英雄选卡**：每用户看到自己可领的卡牌网格（牌堆效果）
    4. **确认领取**：卡牌翻面 + 锁定
    5. **完工提交**：发布到校核室（走现有 addVerification）
  - **数据**：CLEAN-WEEKLY-BE 已落（2 commits: 993c48a + a768351）
  - **复用块面**：UI.Card + UI.Modal + UI.Progress
  - **块面缺口**：UI.HeroPick（卡牌网格 + 翻面动画）= 新组件
  - **注意**：BE 已就绪，只需 FE 5 段流程 UI
