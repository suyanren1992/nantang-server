  「对不对？素食是素食，宿宿舍的那个订餐是订宿舍的餐啊。
   但是呢，我们合作社大院里面有一个厨房，这个厨房它是共享厨房。
   共享厨房和订餐是完全两个概念，一个是有厨师做，由这个宿舍的管理员去发布菜单，
   另一个是自己做，也就是说，在住住在这个宿舍的合作社的成员，他们可以去使用啊，
   包括外来的人也可以去使用，但是使用前提是大家不要冲撞在一起，
   所以共享厨房是共享厨房，订餐是订餐，这是两个概念，
   而这个共享厨房，就是对应着全茂业里面的那个厨房，
   里面的那个放置物品的那个厨房」

  设计稿已落盘：方案/设计/UI-DESIGN-共享厨房_2026-07-31.md
  含 4 表 + 10 端点 + 3 Tab UI + 5 处与社区副本相通

【施工内容 · 4 表 + 10 端点 + 8 测试】

  ### 第 1 步：立 4 张新表（server/models.py）

  1. **PotluckEvent**（接龙事件）
     - event_id PK AUTOINCREMENT
     - organizer_id FK → user.id
     - title / dish / event_at / capacity / current_count / description
     - status: open / full / closed / done

  2. **PotluckParticipant**（接龙参与者）
     - participant_id PK
     - event_id FK / user_id FK
     - role: participant / organizer
     - portion / joined_at
     - UNIQUE(event_id, user_id)

  3. **KitchenSlot**（厨房时段）
     - slot_id PK
     - start_at / end_at / capacity (DEFAULT 10)
     - booker_id FK / group_name / dish / party_size
     - status: open / pending / approved / occupied / done
     - note

  4. **SharedItem**（共享物品·冰箱）
     - item_id PK
     - name / category: food/condiment/tool/other
     - owner_id FK / location: fridge/cabinet/counter (DEFAULT fridge)
     - quantity / produced_at / expired_at
     - note

  ### 第 2 步：建 server/routes/kitchen.py（新文件）

  10 端点：
  1. GET  /api/kitchen/potluck/list       — 接龙列表（query: status）
  2. POST /api/kitchen/potluck/create     — 创建接龙
  3. POST /api/kitchen/potluck/join       — 报名接龙
  4. GET  /api/kitchen/slots/list         — 时段列表（query: start_date）
  5. POST /api/kitchen/slots/book         — 申请时段（容量规则）
  6. POST /api/kitchen/slots/release      — 释放时段
  7. GET  /api/kitchen/items/list         — 共享物品清单（query: category）
  8. POST /api/kitchen/items/add          — 放入物品
  9. POST /api/kitchen/items/take         — 取出物品
  10. DELETE /api/kitchen/items/{id}      — 移除物品（owner/admin）

  容量规则：
  - party_size ≤ 10：自动 approved
  - 10 < party_size ≤ 20：pending（待管理员审）
  - party_size > 20：reject（拒绝·提示拆分）
