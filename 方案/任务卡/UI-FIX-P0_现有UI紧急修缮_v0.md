## 用户原话报（最高痛感，1-7 项先做）

  ① 冰箱放东西按钮无反应
     - 定位：app.js 找"放入冰箱"/"放进冰箱"按钮 onClick
     - 现状：app.js:3068 _openQuickSheet('🧹 快速打扫') 已有，但物品放冰箱无对应入口
     - 修复：走 app.js:2388 _quickForm('放入物品') 已有，绑定到冰箱按钮

  ② 校核卡点进去没卡片 + 提示文字看不清
     - 定位：ui-cardroom.js 校核人视角
     - 现状：校核卡片无 .ui-card 包装，按键没在卡片上，提示文字与背景混色
     - 修复：用 W6-UI-CARD-API 已落地的 UI.Card 包校核卡 + 修颜色对比度（4.5:1）

  ③ 校核自己卡片提示错
     - 定位：ui-cardroom.js 校核流程
     - 现状：用户校核自己提交的卡片，提示词是"不能消耗自己的"
     - 修复：改为"不能校核自己的卡片，请等待他人校核" + 阻断按钮

  ④ 在线人数 0 + 翻牌没显示已入住人员（同一根因）
     - 定位：core.js presence 三态渲染 + sync_all.presence
     - 现状：W6-P-FE 已上线（04d4f0e），但 sync 间隔可能太长或渲染层未刷新
     - 修复：缩短 sync 间隔到 30s + renderProfile('my_village') 加 presence 列表

  ⑤ 任务审核人默认应是自己
     - 定位：core.js 任务发布表单
     - 现状：发任务时审核人字段为空
     - 修复：默认填充 CURRENT_USER，指定他人时才改

  ⑥ 任务撤回要两次（无人领取应直接撤回）
     - 定位：core.js 任务撤回流程
     - 现状：第一次撤回被拒，第二次才成功
     - 修复：无人领取时一次撤回（status: open → retracted），领取后才需 approve

  ⑦ 字号不统一（公约/住宿/归档文件时间线）
     - 定位：theme.css 字号体系
     - 现状：红队 A P0-2 指出 CSS 变量双轨（main.css vs theme.css）
     - 修复：合并为单一 --g-* 体系，全局替换 main.css 引用
