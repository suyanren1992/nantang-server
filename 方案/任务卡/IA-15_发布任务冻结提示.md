# IA-15 发布任务冻结提示缺失（一营+二营施工）

> 来源：砚仁反馈（发布任务后没有提示已冻结 NT，工作台也看不到冻结金额）
> 施工：Claude Code（一营前端）+ 豆包 Codex（二营后端）｜验收：施工二营/丞相
> 优先级：**P1**（用户体验问题，不影响资金安全）
> 法源：砚仁终审

---

## BUG 描述

发布任务后：
1. 没有 toast 提示"已冻结 N NT"
2. 工作台页面没有展示冻结余额

## 根因

- 服务端 `create_task`（tasks.py:163）返回 `{"ok": True, "task_id": "xxx"}`，**不返回冻结金额**
- 前端 `doPublish`（core.js:690-724）成功后只调 `clearPubForm()` 没冻结 toast
- 工作台（core.js `renderMyTasks`）没有展示 `my_escrow` 模块

## 施工内容

### 二营（后端，先行）

**tasks.py `create_task` 返回体加冻结金额**：

```python
# L163 附近，原 return
return {"ok": True, "task_id": task_id}
# 改为
return {"ok": True, "task_id": task_id, "escrow_amount": 0 if req.scope == "camp" else req.reward * req.slots}
```

### 一营（前端，二营交付后）

**① doPublish 成功后加冻结 toast**（core.js:721 附近）：

```javascript
// HTTP 模式，syncTask 回调成功后
showToast('✅ 已发布，冻结 ' + nt * (data.slots||1) + ' NT', 'ok');
```

**② 工作台加冻结余额展示**（core.js renderMyTasks 顶部）：

从 `API.syncAll` 或 `API.fetchTasks` 的返回数据中读取用户冻结金额（`my_escrow`），在工作台顶部加一行：
```
❄️ 已冻结：N NT
```

> 注：`sync_all` 返回体已有 `my_escrow` 字段（NT-P0-4a 已加），前端直接用即可。

### ③ ?v= 同步

core.js v39→40 或更高（视 IA-14 进度）
