### 🔴 Q1：但书与铁律 5 的触发顺序没写——丞相可在朝会前抢先亲工

**事实**：施工流程铁律 5 规定「同卡打回 ≥3 次，自动升级朝会」。K-2 案中，二营打了 3 次（6dc017d → 9d36bac → 8b8def2），第三次后丞相升朝会、砚仁 18:40 授权破例、丞相 18:43 亲工——这个路径是合规的。

**但但书本身没有写「亲工必须发生在铁律 5 朝会程序之后」**。考虑这个场景：二营打回 2 次，丞相判断「再打下去也是盲改，三条件已满足」，直接在第三次打回前亲工——此时铁律 5 还没触发（不到 3 次），但书却已经激活了。等于丞相可以绕过朝会程序自行决定亲工。

**核查方法**：
```
grep "打回" BUG_TRACKER.md | 统计每卡打回次数
找任一卡打回=2时若丞相亲工，即证实此漏洞
```
当前无此案例——但它是一个尚未触发的逻辑漏洞，不是不会触发。

**建议**：但书加一句 **「亲工前须先走完铁律 5 朝会程序（打回≥3 次升朝会→砚仁定夺→授权破例），未走完朝会程序而亲工者，commit 视为越权，对营有权 revert」**。

### 🟠 Q3：「条件②处方已实证」的认定权在丞相——而丞相认定自己开的处方

**事实**：K-2 案中，丞相刮卡实证处方（定位到三个 `@pytest.mark.asyncio` 裸装饰器 + 一个缺 `await s.commit()` 的两段式提交），然后丞相自己执行了这个处方。处方精确到行（删 L76/L128/L179 三行 + L196 加一行 `await s.commit()`），的确经过了刮卡验证。**但是——认定"处方已实证"的是丞相本人，执行处方的也是丞相本人。**

这与铁律 9 的精神冲突：铁律 9 说「丞相任何裁定先分级再定程序」「宪法/程序法级：丞相拟票→两营对抗一轮→砚仁批，三视角全过才生效」。但书本身是宪法级修正，但它豁免了自己——亲工决策不需要走两营对抗。

**核查方法**：
```
git log --all --format="%h %s" --grep="丞相亲工" | wc -l
# 如果未来此数字 >1，且每案都没有"亲工前两营对抗"记录，即证实此漏洞
```

**建议**：条件②加一句 **「处方须经对营对抗验证（对营审处方 diff + 跑实证命令，确认处方与根因因果关系成立），对抗通过方可亲工；紧急豁免须在 Daily 标注「跳对抗」+ 事后补对抗」**。

### 🟠 Q4：三条件是"且"关系，但条件①和条件③有循环依赖

**事实**：条件①「客观做不了：施工营缺密钥/环境/权限，盲改连败已实证」——但"盲改连败"是**施工营自己施工失败**，这不等于"客观做不了"。K-2 案中，二营三次打回的原因分别是：
1. User 构造错（name= 无效关键字）——**施工方写错了测试数据**
2. asyncpg 单连接并发错（event loop 错位）——**施工方没对齐 pytest mark**
3. 函数级裸装饰器覆盖 module loop_scope ——**施工方对 pytest 机制不熟**

这三个全是**知识缺陷**，不是**客观环境限制**。"缺 PG 连接串"才是真正的客观限制——只有丞相有 Neon PG 的直连 endpoint。但第一、二次打回甚至都没跑到真 PG 那一步——它们在 SQLite 端就构造错了测试数据。

**所以问题来了**：如果施工营三次打回中有两次是因为知识缺陷而非环境限制，"盲改连败已实证"能等于"客观做不了"吗？还是说知识缺陷应该通过"丞相给施工营补课"来解决，而不是"丞相自己下场"？

**核查方法**：
```
git log --all --format="%h %s" -- "项目/实景游戏移动端代码_new/server/tests/test_pg_locks.py"
# 追踪 K-2 的三次打回 diff，逐条标注根因是"知识缺陷"还是"客观环境限制"
# 预期：前两次是知识缺陷，第三次也是（装饰器机制不熟），只有"缺 PG 连接串跑验证"是客观限制
```

**建议**：条件①改为 **「施工营在已有全部信息下仍无法独立完成：丞相已给出诊断方向+补课材料，施工营仍连续失败 ≥2 次」**——把"客观做不了"的门槛从"盲改连败"提升为"给了方向还是做不了"。

## 修二 · 入口协议加呈批格式锚点

### 结论：🟡 修正（减重——降为入口协议引用链，不入宪法正文）

---

### 🔴 Q1：格式规范入宪法层过重——三段式是风格级问题，不是宪法级

**事实**：操作总则 v2.0 的定位是「一门三规——可机检的规矩全在闸里，人的判断全在下面三条」。三规是：
- 一 · 正文不动（不能改 source/done 正文）
- 二 · 口说无凭（结论必挂锚点）
- 三 · 拿不准就停（规矩没写就停）

这三条是**行为红线**——违反任何一条都会造成不可逆伤害（覆盖原文/结论无据/自由发挥闯祸）。

三段式格式是**效率问题**，不是**安全问题**。AI 没用三段式→砚仁多花 30 秒翻文件，但不会丢数据、不会改错文件、不会产生无锚点结论。把效率问题升到宪法层，混淆了"不能做的事"和"最好这样做的事"。

**核查方法**：
```
# 统计过去 48 小时内 AI 心跳/交付物中三段式与非三段式的比例
grep -c "🎯" Log/Daily/2026-07-26.md  → 0（今天的 Daily 纯心跳和闸报，没有一段用了🎯）
grep -c "🤝" Log/Daily/2026-07-26.md  → 闸报显示"缺🤝"（连今天的 Daily 自己都不符合三段式！）
```
连 Daily 自己都没有三段式——如果把三段式写入操作总则入口协议，每日闸报的「缺🤝」黄灯就从风格提醒变成了"宪法违规"——而谁都懒得去修它，最终变成常态化的黄灯噪音。

**建议**：不入宪法正文。改为**入口协议第 1 条追加**：「呈批给砚仁看的内容用三段式（🎯一句话→🤝请定夺→📎细节），细则见风格指南」。不编号为入口协议第 5 条，而是追加在第 1 条"读本文件→读 Daily→干活"之后作为附注——因为它是"怎么读完之后写"的建议，不是"开工前必须做什么"的指令。

### 🟠 Q2：「📋 整段复制」在 AI 执行时存在歧义——块内即所贴的边界不清晰

**事实**：风格指南提案 g 写「要复制的内容单独代码块标📋整段复制；块内即所贴，块外即所述」。但"所贴"vs"所述"的边界在包含占位符、条件分支、可选参数时是模糊的。

举例：我给砚仁一段需要根据他的环境修改的命令——

````markdown
📋 整段复制
```bash
cd C:\Users\苏砚仁\thinknote\项目\实景游戏移动端代码_new
set PG_DATABASE_URL=<你的PG连接串>
pytest server/tests/test_pg_locks.py -v -k "requires_pg"
```
````

这里 `<你的PG连接串>`——是"所述"（砚仁需要替换）还是"所贴"（砚仁直接复制然后报错）？草案没有区分占位符语法。「块内即所贴」太绝对了，实际交付中这种半贴半改的场景非常多。

**核查方法**：
```
# 统计过去一周 BUG_TRACKER 和任务卡中"需要砚仁替换参数"的命令行数量
grep -r "<你的\|替换为\|改成你的\|your-" BUG_TRACKER.md 方案/任务卡/*.md | wc -l
```
预期：大量命令包含占位符。如果全都标📋，砚仁会踩坑。

**建议**：风格指南提案 g 追加一句 **「含占位符的命令用 `📋 整段复制（替换 <...> 后执行）」`，明确区分"复制即用"和"复制后改"。」**

**事实**：修二写「丞相换窗口后丢格式，翻 4 个文件才找到三段式——高频规矩埋太深」。但看中堂备忘录的换窗口指引段（L44-49）：

### 🟡 Q4：闸要不要查三段式？修二没说

**事实**：风格指南已写「「🤝」行的存在性闸会查」。但如果修二把三段式提升到操作总则入口协议层，闸的检查项要不要同步升级？目前 `vault_gate.py` 的 `HB_RE` 正则只检查心跳格式，不检查三段式。如果未来要机检三段式——

1. **怎么查🎯？** 🎯emoji 后必须跟一句话——什么叫"一句话"？有没有句号算一句吗？换行算结束吗？正则写不出来。
2. **怎么查📎？** "细节在后"是语义约束，不是形式约束。AI 可以在🎯后写 300 行再写📎——闸怎么知道那 300 行不是"细节"？
3. **误报率预估**：闸当前已经有 9 项黄灯检查，每日报 85+ 条版本号文件名黄灯（全是历史债）。再加一个语义模糊的格式检查，黄灯清单会更长→砚仁更不看了。

**建议**：**闸不查格式**。格式留给人的判断（风格指南定位：榜样不是法律），闸只管可机检的形式层（心跳格式/Schema 受保护/文件名禁令等）。

## 太傅注

- **补课章节**：补课 11（软件工程基础）——权力分立（separation of powers）：执行权与立法权分开、裁判不能同时是运动员。修一是给执行权开例外口子，必须用程序约束（朝会→授权→对抗→入档）防止例外吃掉规则。
- **人话原理**：丞相亲工就像裁判下场踢球——K-2 这次踢进了，但下次裁判可能觉得自己比球员强、不等三次犯规就下场。把"什么时候能下场"写死，才不会从例外滑成常态。
- **不这样做会怎样**：但书没有程序闸门→丞相在 2 次打回时就亲工→铁律 5 被绕过→施工营失去"三次机会"的保护→丞相越来越累、施工营越来越废。修二没有减重→格式规范膨胀到宪法层→闸报黄灯从 9 项变 11 项→砚仁更不看闸报→真正的红灯也被淹没。
