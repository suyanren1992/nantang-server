# IA-14 任务卡片重复+乱码（一营施工）🔴

> 来源：砚仁反馈（发布任务后出现两张卡片，一张正常一张乱码，之前修过但未根治）
> 施工：Claude Code（一营）｜验收：施工二营
> 优先级：**P0**（任务系统核心体验 BUG，用户可见）
> 法源：砚仁终审

## BUG 描述

发布一个任务后，任务大厅出现**两张卡片**：
- 一张标题正常显示（中文标题）
- 一张标题是 server ID 乱码（如 `T260730123456-abc`）

## 根因（已定位）

`core.js:341-352` 的 `fetchTasks` 回调中，去重逻辑用了错误字段名：

```javascript
// L345: 按 server ID 查 — 本地任务用标题做 key，查不到
var exists = AppData._data.tasks[t.id];
// L348: 按 title 比 — 本地任务标题存在 name 字段，lt.title 是 undefined → 永远匹配失败
exists = localTasks.find(function(lt){return lt.title===t.title && lt.publisher===t.poster;});
// L351: 匹配失败 → 再存一条 → 重复
AppData._data.tasks[t.id] = {name:t.id, ...}  // name 字段存了 server ID → 显示乱码
```

**数据流**：
1. 本地 `addTask` → `tasks["帮我扫厨房"]`（标题做 key，`name="帮我扫厨房"`，**无 `title` 字段**）
2. 服务端创建成功 → 返回 `task_id = "T260730..."`
3. `fetchTasks` 拉回 → L345 查 `tasks["T260730..."]` → 不存在
4. L348 查 `lt.title === t.title` → 本地 `lt.title` 是 `undefined` → **匹配失败**
5. L351 存 `tasks["T260730..."] = {name:"T260730...", title:"帮我扫厨房"}` → 重复 + 乱码

## 施工内容

### ① 修去重逻辑（core.js:348）

```javascript
// 改 lt.title 为 lt.name（本地任务标题存在 name 字段）
exists = localTasks.find(function(lt){return lt.name===t.title && lt.publisher===t.poster;});
```

### ② 修 name 字段（core.js:351）

```javascript
// 改 name:t.id 为 name:t.title（用标题而非 server ID 做显示字段）
AppData._data.tasks[t.id] = {name:t.title, title:t.title, ...}
```

### ③ 排查同类问题

`core.js:1145` 也有同样的 `fetchTasks` 回调，同样用了 `t.id` 做 key：
```javascript
if(!AppData._data.tasks[t.id]){AppData._data.tasks[t.id]={name:t.id,...}}
```
同样需要修：去重条件加 `lt.name===t.title`，name 字段用 `t.title`。
