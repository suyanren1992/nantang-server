  A1. 任务串键打开空白 + 闪烁
     - 定位：core.js / app.js 找任务"展开/串键"事件
     - 排查：是否 modal/sheet 嵌套、z-index 冲突
     - 修复：单 sheet 实例 + 关闭动画 + 不挂载空 div

  A2. 弹窗关不掉（X 叉无反应）
     - 定位：app.js _closeSheet / _closeModal
     - 排查：事件委托是否被 [data-action] 拦了
     - 修复：所有 X 叉统一 [data-action="close"] + onAction 委托

  A3. 关掉弹窗又弹回活动页

     - 修复：扩展 _closeAllSheets() 到所有 open* 函数前置

  A4. 物品没进冰箱储存库
     - 定位：app.js _quickForm('放入物品') 路径
     - 排查：① 修了权限提示但写入 API 没接
     - 修复：onSubmit 调 API.addItemStorage + 错误 toast + 成功后 refreshStorage

  A5. 弹来弹去没处找（无明确返回）
     - 定位：app.js 路由/back 按钮
     - 排查：history.back() 是否生效 / 是否多个 sheet 互跳
     - 修复：明确"上一个 sheet"栈 + breadcrumb 或统一 home 入口
