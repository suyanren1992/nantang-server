## B. UI.Alert 通用块 + 校核室接入（升级）· 改 v0
━━━━━━━━━━━━━━━━━━━━━━━━━━

  修法（v1 增强）：
  1. nantang-mobile/js/ui-primitives.js 加 UI.Alert 方法
     ```js
     UI.Alert = {
       show({ type, title, message, actions, dismissible }) {
         // 1. 创建 modal 容器（UI.Card 风格）
         // 2. 渲染标题 + 图标（按 type）
         // 3. 渲染消息（支持多段）
         // 4. 渲染 actions（按钮组）
         // 5. 返回 Promise<value>
       }
     };
     ```

  2. 形态（UI.Card 风格·用 --g-card 主题）：
     ┌──────────────────────────────────────┐
     │  ⚠️  标题                              │
     │  ───────────────────────────────────  │
     │  消息内容（一段或多段）                  │
     │  ───────────────────────────────────  │
     │        [取消]   [确认]                 │
     └──────────────────────────────────────┘

  3. API：
     UI.Alert.show({
       type: 'warning' | 'error' | 'info' | 'success',
       title: '确认校核',
       message: '是否确认校核此任务？',
       actions: [
         {label: '取消', value: false, style: 'ghost'},
         {label: '确认', value: true,  style: 'pri'}
       ]
     }).then(value => { if (value) 校核逻辑 });

  4. 校核室接入（首用例）：
     - 校核卡片打勾 onclick → UI.Alert.show({...})
     - 替换原 _showCardPopup 悬浮气泡

  5. 3 处复用（首期）：
     ① 退房 → 「确认退房」
     ② 任务撤回 → 「确认撤回」
     ③ 申请时段 >10 人 → 「待管理员审核」提示

  验证：
  - 校核室打勾 → 弹 UI.Alert 卡片
  - 退房/任务撤回/时段审核都弹 UI.Alert
  - 全部用 var(--g-card) / var(--g-radius) / var(--g-shadow) 主题
  - ?v= bump：ui-primitives.js → 4
