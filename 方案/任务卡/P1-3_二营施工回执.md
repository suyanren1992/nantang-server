> **太傅注**：①`populate_existing=True` 是 SQLAlchemy 行锁的必配件——`with_for_update` 只发 SQL 层 `SELECT ... FOR UPDATE`，但 ORM 若 identity map 已有该对象会**跳过刷新**返回旧值，加 populate_existing 强制用锁查结果覆盖缓存（补课：SQLAlchemy Session identity map + populate_existing）。②为何危险＝钱操作紧邻——`+= reward` 基于旧余额写回会吞掉并发扣款，属「丢失更新」经典并发 bug。③锁只在 PG 真生效，SQLite 单写者掩盖锁序错，故锁正确性测试一律 requires_pg 门控。
