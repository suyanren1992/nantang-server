## A. 田间管理 P0 — `9067611`

**根因**：api.js 田间 5 端点路径缺 `/api` 前缀 → fetch 404 → 前端恒走本地假数据。

**改动**（nantang-mobile/js/api.js）：
- `getFields`: `/fields` → `/api/fields`
- `getFieldPlot`: `/fields/{id}` → `/api/fields/{id}`
- `harvestFieldPlot`: `/fields/{id}/harvest` → `/api/fields/{id}/harvest`
- `waterFieldPlot`: `/fields/{id}/water` → `/api/fields/{id}/water`
- `fertilizeFieldPlot`: `/fields/{id}/fertilize` → `/api/fields/{id}/fertilize`

**验证**：DevTools Network `/api/fields` → 200（非 404）。

## B. UI.Alert 通用块 — `76e488d`

**根因**：校核提示字 P2（v0）→ 砚仁批甲升 v1："不只改一处颜色，建 UI.Alert 通用块。"

**改动**：

### ① ui-primitives.js：UI.Alert 组件（+67 行）
```js
UI.Alert.show({
  type: 'warning' | 'error' | 'info' | 'success',
  title: '确认校核',
  message: '是否确认校核此任务？',
  actions: [{label:'取消', value:false, style:'ghost'}, {label:'确认', value:true, style:'pri'}]
}).then(value => { if (value) 校核逻辑 });
```
- 4 态图标 + 主题令牌（--g-card/--g-radius/--g-shadow）
- 3 种按钮样式（pri/danger/ghost）+ 背景点击关闭
- Promise 式 API

### ② 校核室接入（ui-cardroom.js）
- `_confirmWitness`：旧自定义 modal → `UI.Alert.show(...)`

### ③ 退房确认（ui-accom.js）
- `_accomConfirmCheckout`：包裹 UI.Alert 确认（显示天数 + NT 明细）

### ④ 任务撤回（data.js）
- `withdrawTask` 无人领路径：UI.Alert 确认后撤回

### ⑤ 时段审核 >10 人
- ui-kitchen.js `_doBookSlot`：partySize>10 → 服务端返回 pending → UI.Alert 提示

**验证**：4 处弹窗全部使用 UI.Alert 通用块 · --g-card 主题令牌统一。
