## F. 模块混用级（治理事故，最高优先级）
━━━━━━━━━━━━━━━━━━━━━━━━━━

  F1. 全貌页 vs 个人工作台 时间线/档案室 跳转串
     - 现象：从个人工作台点「时间线」→ 进入的不是「我的时间线」而是「全貌页时间线」
     - 从时间线点「档案室」→ 打不开/看不到内容
     - 定位：app.js 时间线路由 + 档案室入口 href/data-page
     - 修复：
       1. 拆开「我的时间线」vs 「全貌时间线」两个独立 route
       2. 个人工作台默认进入「我的时间线」
       3. 档案室入口在「我的时间线」内能正常打开

  F2. 全貌页设置按钮一直有问题（多次未修对）
     - 现象：点击无反应 / 弹错 / 重复弹
     - 定位：core.js _openSettings / _showSettingsSheet
     - 排查历史：可能被多次加补丁但没解决根因
     - 修复：删除所有旧代码，**重写一个干净的 _openSettings()**：
       - 用 UI.Modal（已有）统一壳
       - 单一 [data-action='open-settings'] 入口
       - 头像按钮 + 全貌页按钮都走同一个函数

  F3. 个人工作台加了重复的设置按钮
     - 现象：点头像有设置入口，工作台内部又冒一个
     - 定位：app.js _renderProfile vs _renderWorkbench
     - 修复：工作台内**删除**设置入口（统一走头像点开）

━━━━━━━━━━━━━━━━━━━━━━━━━━
## G. 冰箱（写入流 + 列表刷新）
━━━━━━━━━━━━━━━━━━━━━━━━━━

  G1. 冰箱「放入物品」按钮无反应
     - 现象：点按钮不弹窗 / 不触发任何动作
     - 定位：app.js 找「放入物品」/「放进冰箱」按钮 onClick
     - 修复：onClick 调 _openQuickSheet('放入物品') → 弹表单 → onSubmit 调 API.addItemStorage

  G2. 冰箱放入后列表不刷新
     - 现象：填完表单提交，物品没出现在冰箱清单
     - 定位：app.js submit 成功后没调 _refreshStorage
     - 修复：submit 成功后 await API.addItemStorage + 调 _refreshStorage() + toast 成功

## H. 校核室（卡片包裹 + 对比度）
━━━━━━━━━━━━━━━━━━━━━━━━━━

  H1. 校核卡片提示词没在卡片里（字暗+背景暗混一起）
     - 现象：弹出来的提示词字暗，背景也暗，混在一起看不清
     - 砚仁原话：「把这个提醒的内容背景给用卡片蹭出来」
     - 定位：ui-cardroom.js 校核人视角弹窗/toast/卡片
     - 修复：
       1. 所有「提示词/状态说明/等待中」文本**强制用 UI.Card 包裹**
       2. 卡片背景 = --g-bg-elevated（亮）
       3. 文字 = --g-text（明）
       4. 对比度 ≥ 4.5:1（WCAG AA）
     - 验证：浏览器控制台 getComputedStyle 检查

  H2. 下颌室 = 校核室（打字错，砚仁指校核室）
     - 现象：校核室内容没改
     - 定位：ui-cardroom.js 校核室整个页面
     - 修复：用 W6-UI-CARD-API 5 件套全部重包：
       - 校核列表 → UI.Card 网格
       - 校核详情 → UI.Modal + UI.Card
       - 状态/提示/等待 → UI.Card + StatusBadge
