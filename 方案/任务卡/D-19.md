### 发现的问题（全部是测试代码问题，非业务代码）

1. **导入路径不一致**（🔴）：`conftest.py` 使用 `from server.database import ...` 但 App 代码使用 `from database import ...`，导致 SQLAlchemy `Base` 双重注册 → 原版无法收集测试。临时在验收中修了 import（`server.X` → 平级 import）才跑通。**建议 Codex 统一导入风格**。
2. **User 模型假设错误**（🔴）：多个测试使用 `User(name=...)` 但实际模型 `User.id` 即用户名（无 `name` 字段）。验收时逐一修正。
3. **API 路径/签名不匹配**（🟡）：`/api/tasks/list` → 应为 `/api/tasks`；approve 请求体 `{}` → 需 `{doer, action}`；`NTLedger.id` → 应为 `NTLedger.entry_id`；`w.status == "confirmed"` → 应为 `"settled"`。
4. **提现金额低于业务下限**（🟡）：`test_full_capital_loop` 提现 5 NT 但最低提现额为 50 NT。

### 结论

**有条件通过** ✅。22 条测试全部通过，变异抽查断言有效。但上述 4 项测试代码问题需 Codex 修正后才是「真正可维护的测试」。业务代码本身正确。
