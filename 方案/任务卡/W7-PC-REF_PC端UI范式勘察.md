# W7-PC-REF · PC 端 UI 范式勘察

## 一、为什么开这张卡

丞相前两轮（物品流转、抽屉柜分区）都是**先出设计稿、后勘察**，两次都被皇帝指出设计不对，回头才发现 PC 端早有成熟做法。皇帝原话：

> 「UI 界面是要注意的，优化电脑端 `dashboard.html`」
> 「它的摆放方式，还有它的展现方式，也是经过多方的考证的，你也能够做一些参考」

**PC 端 `项目\实景游戏pc端代码\dashboard.html`（864KB / 13313 行单文件）有 63 个 `render*` 函数、9 个 tab，是走过多轮迭代的成熟界面库。**
PC 端已定性：**本地文件 · 已废弃 · 将来重写为管理端**。所以它的**代码没有价值，界面范式有价值**。

丞相已勘察到的两个反转（施工方须复核并扩展）：
1. **正名早已存在**于 PC 端：`:6084 白菜拍卖行`、`:6085 萝卜议事厅`、`:6079 素社食堂` —— 移动端叫「拍卖」「议事厅」是**退化**
2. **档案室已有实现**：`renderArchiveHub:7811` / `renderCommunityArchives:8243` / `renderArchiveTaskRow:7962` / `renderMemberDossier:8274`

## 三、问题清单（逐条作答，这是本卡全部内容）

### P-1 · 九个 tab 的布局范式
`:6077-6085` 定义 9 个 tab（实景地图 / 客栈 / 素社食堂 / 集市 / 茶馆 / 桌游室 / 档案室 / 白菜拍卖行 / 萝卜议事厅）。

逐个回答：
1. 这个界面**分几栏**？主区放什么、侧区放什么？
2. 内容用**什么形态**承载？（卡片网格 / 列表行 / 表格 / 时间轴 / 分组折叠）
3. 有**筛选/搜索/排序**吗？入口在哪、怎么触发？
4. **空态**长什么样？（有没有插图、文案、引导按钮）
5. **计数徽章**怎么显示？（`:6078 confirmedGuests+'/'+totalBeds+'人'`、`:6080 listedCount+'件在售'` 是范式，逐个记全）
6. 有没有**分组**？按什么分（按人 / 按类别 / 按时间 / 按状态）？

### P-2 · 「我的物品 ↔ 集市」双向连通范式（重点）
丞相已知：`:4668` 注释「我的物品（三卡片布局，与集市同步）」、`:4670-4672` 按 status 分堆、`:4983` 集市读同一 `data.inventory`、`:4991` 按 owner 分组。

**请补全**：
1. 三卡片具体是哪三张？每张标题、内容、操作按钮是什么？
2. 上架的**交互流程**逐步是什么？（点哪里 → 填什么 → 确认 → 结果反馈）
3. 已上架物品在「我的物品」里怎么显示？有没有「下架」？下架在哪？
4. `status` 六档（`unlisted` / `listed` / `reserved` / `display` / `sold` / 其他）在**界面上分别长什么样**？用什么视觉区分（颜色/徽章/置灰）？
5. `price: 0`（如 `:1990 旧画框3个 category:交换 price:0`）界面上显示成什么？「免费」还是「交换」？
6. 集市里点一件物品，能否**跳回物主的物品详情**？怎么跳？

### P-3 · 档案室范式（台账 #29 的现成参考）
`renderArchiveHub:7811` / `renderArchiveList:1305` / `renderCommunityArchives:8243` / `renderArchiveTaskRow:7962` / `renderMemberDossier:8274` / `renderFinanceReports:8172`

1. 档案室**分几类**？每类怎么进？
2. 归档的东西按什么**组织**（时间倒序 / 按人 / 按类别 / 按项目）？
3. 怎么**查**？有搜索吗？有筛选维度吗？
4. `renderArchiveList` 的 `viewMode` 参数有哪几种视图？各是什么样？
5. 「成员档案」(`renderMemberDossier`) 长什么样？一个人的历史怎么摊开？

### P-4 · 工作台范式
`renderWorkspace:4453` 及其 `workspacePanel` 各值（已知含 `items`）

1. 工作台一共几个面板？各是什么？
2. 面板之间怎么切换？切换控件在哪、什么形态？
3. **从一个面板能否回到其他任意面板**？（⚠ 移动端 UI-4 就是在这里出了单向门 bug）

### P-5 · 通用组件与视觉语言
1. 卡片(`.card`)的统一样式是什么？（内距/圆角/边框/标题写法）
2. 按钮有几档？（`.btn pri` / `.btn` / 其他）各用在什么场景？
3. 头像怎么画？（`avatarCircle(owner,16,0)` 的参数含义）
4. **弹层/抽屉**有几种？（`renderHubSlideContent:5899`、`renderHubDropdown:6067`、`picker-dropdown`）各在什么场景用？
5. 有没有**贯穿全站的空态组件**？还是每处各写一遍？

### P-6 · 移动端可抄性判定（本卡最终价值）
对上述每一条范式，标一个判定：

| 判定 | 含义 |
|---|---|
| ✅ **可直抄** | 小屏也成立，移动端应照此做 |
| ⚠ **需改造** | 思路对但形态要改（如三栏→单栏纵向堆叠），**写清怎么改** |
| ❌ **不适用** | 依赖大屏/鼠标悬停/宽表格，移动端不做 |
