## P-2 · 「我的物品 ↔ 集市」双向连通范式

### 2.1 三卡片是哪三张？

集市发布面板（`renderHubSlideContent:5914-5933`）、工作台物品面板（`renderWorkspace:4668-4688`）**共用同一套布局**：

| 卡片 | 集市（hub bazaar） | 工作台（workspace items） | 形态 |
|---|---|---|---|
| **Card 1: 已上架** | `:5921` 紧凑列表 | `:4676` 紧凑列表 | 每行：icon+名称+价格+[⬇下架] |
| **Card 2: 未上架** | `:5926` 图标网格 + 搜索 | `:4681` 图标网格 + 搜索 | 3 列网格，每格：icon+名称+价格+[点此上架] |
| **Card 3: 添加物品** | `:5932` toggle 按钮 + 表单 | `:4687` toggle 按钮 + 表单 | `_renderAddItemForm`（`:8356`）：名称+类别下拉+价格+确认 |

### 2.2 上架交互流程

```
1. 在「我的物品」（workspacePanel='items'）
   → Card 2（未上架网格）中点击物品格子
   → 调用 listItemToBazaar(itemId) → status='listed'
   → _refreshItemViews() 同时刷新工作台+集市+hub dropdown

2. 在集市浏览态（bazaarAddOpen=false）
   → 点击「＋ 发布」→ bazaarAddOpen=true
   → 展开三卡片：已上架列表 / 未上架网格 / 添加物品
   → 从「未上架」网格点击物品 → 上架
   → 或从「添加物品」新加物品（初始 status='unlisted'）

3. 物品字段结构（:8370）：
```

### 5.3 头像怎么画？

```javascript
// dashboard.html:9647-9651
function avatarCircle(seed, size, styleIdx) {
  var name = typeof seed === 'string' ? seed : CHARACTER_SEEDS[seed % CHARACTER_SEEDS.length];
  var url = 'https://api.dicebear.com/7.x/' + AVATAR_STYLE + '/svg?seed='
          + encodeURIComponent(name) + '&size=' + (size*2) + '&radius=50';
  return '<span style="display:inline-block;width:'+size+'px;height:'+size+'px;'
       + 'border-radius:50%;overflow:hidden;flex-shrink:0">...<img ...></span>';
}
```

| 参数 | 含义 |
|---|---|
| `seed` | 字符串=直接用；数字=取 `CHARACTER_SEEDS[seed % N]` 作为 DiceBear seed |
| `size` | 渲染尺寸（px），实际请求 size×2 做 retina |
| `styleIdx` | PC 端未使用（统一 `AVATAR_STYLE`），保留参数兼容 |

📌 **头像样式统一圆形**，DiceBear 7.x API，固定 style。
